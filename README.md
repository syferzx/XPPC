# XPPC

Reproductor multimedia portable para Windows.

[![Descargar para Windows](docs/download-windows.svg)](https://github.com/syferzx/XPPC/releases/latest/download/XuperPC-Windows-x64-BAT.zip)

## Descargar y abrir

1. Descarga **XuperPC-Windows-x64-BAT.zip** desde [la última versión](https://github.com/syferzx/XPPC/releases/latest).
2. Haz clic derecho en el ZIP y elige **Extraer todo**.
3. Abre la carpeta extraída y ejecuta **Iniciar.bat**.

Conserva la carpeta `Engine` junto al BAT y deja abierta la ventana de inicio. No necesitas instalar Python, FFmpeg ni BlueStacks. Para detener el servidor, pulsa **Ctrl+C** en esa ventana.

## Actualizar

Espera a que terminen tus descargas y cierra el servidor anterior. Conserva tu carpeta **Datos** y los archivos descargados al sustituir el programa. El portable publicado no incluye datos personales.

## Funciones

- Películas, series, anime y televisión en vivo.
- Favoritos y progreso guardados en este PC.
- Preferencias de audio y subtítulos desde el círculo **PC**.
- [Mis descargas](docs/DESCARGAS.md), con MKV original o MP4 compatible.

La disponibilidad y los idiomas dependen del servicio utilizado. No incluye VPN.

## Distribución

Este repositorio se utiliza para distribuir el portable y sus instrucciones. Para usar la aplicación, descarga el ZIP BAT de **Releases**. Los archivos automáticos **Source code** de GitHub no son el portable.

El código publicado anteriormente permanece en el historial y en las etiquetas antiguas.
